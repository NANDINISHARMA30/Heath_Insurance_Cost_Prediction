 A SML Project
This project aims to predict health insurance costs based on various factors like age, BMI, smoking habits, and other demographic details using Machine Learning (Linear Regression & other models).

🛠️ Tech Stack
Programming Language: Python 🐍
Libraries: Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
Machine Learning Model: Linear Regression

📊 Dataset Description
The dataset contains the following features:

Feature	Description
age:	Age of the insured person
sex:	Gender (male/female)
bmi:	Body Mass Index (health indicator)
children:	Number of dependents
smoker:	Whether the person smokes (yes/no)
region:	Location of the insured person
charges: Target Variable – Insurance cost

🔍 Model Performance
The best-performing model achieved:

Accuracy Score: 0.76 (76% variance explained)
